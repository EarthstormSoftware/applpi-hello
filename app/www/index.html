Identity

The Pi's name, which SSH knows it by: it's set when the card is flashed.

Web Access

A password is set.

With a password set, the browser asks for it (any username). It's sent unencrypted, so it keeps out other people on your network rather than a determined attacker.

Diagnostics

Over SSH: journalctl -u juggle-app.

Updates

deploy.ps1 <name> -WiFi sends a new version over the network: the Pi tries it, and goes back to this one if it doesn't keep running.

Wi-Fi

Name and Setup Mode

The Pi's name, and its Wi-Fi when it can't reach this page, are changed in its setup mode: it restarts with the Juggle-SETUP Wi-Fi network and a setup page, for as long as set below, then carries on with its settings unless new ones are saved there.

Restart and Reset

Reset puts every setting on these pages back to its default (the web password too). A factory reset also makes the Pi forget its name, Wi-Fi and SSH keys, and start in setup mode as a new Pi.

MQTT lets home automation software such as Home Assistant or Node-RED read and change the greeting.

Home Assistant

Home Assistant adds the greeting automatically (MQTT discovery), as a text box. Turning this off removes it again. Only change the prefix if Home Assistant's has been changed.
